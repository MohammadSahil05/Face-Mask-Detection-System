# 😷 Face Mask Detection System

Real-time face mask detection using Computer Vision and Deep Learning.

---

## 🚀 Overview

The Face Mask Detection System is a Computer Vision and Deep Learning project that identifies whether a person is wearing a face mask through a live webcam feed. The system helps demonstrate real-time object detection and image classification techniques using modern AI technologies.

---

## ✨ Features

* 😷 Face Mask Detection
* 🎥 Real-Time Webcam Monitoring
* 🧠 Deep Learning-Based Classification
* 👤 Face Detection
* 📊 Live Prediction Results
* ⚡ Fast and Accurate Detection

---
